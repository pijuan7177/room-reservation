# AGENTS.md

Spring Boot 4.1.2 REST API (Java 25, Maven) for room reservations. Single module, package
`com.rreserv.room.reservation` (note the doubled `room`). Requires local PostgreSQL on
`localhost:5432`.

## Commands

Use the wrapper (pins Maven 3.10.0; a first run downloads it and can take a few minutes):

- Test: `.\mvnw.cmd test` (PowerShell) or `./mvnw test`
- Single class: `.\mvnw.cmd -Dtest=RoomReservationApplicationTests test`
- Single method: `.\mvnw.cmd -Dtest=RoomReservationApplicationTests#contextLoads test`
- Run app: `.\mvnw.cmd spring-boot:run`
- Package (also runs Asciidoctor REST Docs at `prepare-package`): `.\mvnw.cmd package`

Requires JDK 25 (`pom.xml`).

## Current blockers and gotchas

- Liquibase runs on startup and test. The master changelog is
  `src/main/resources/db/changelog/liquibase-changelog.xml` (wired via
  `spring.liquibase.change-log`), with per-table changesets under `changes/`. `ddl-auto=none`, so
  schema changes belong in changesets, not entity auto-DDL.
- Already-applied changesets are checksum-validated; never edit them. Add a new
  `changes/00N-*.xml` changeset and include it in the master changelog.
- Changelog XML headers use the bundled `dbchangelog-latest.xsd`; the versioned `5.0` XSD failed to
  resolve under Liquibase 5's secure parsing.
- `RoomControllerIntegrationTests` uses `@ActiveProfiles("test")`, so it runs against
  `rreserv_test` with `src/test/resources/db/changelog/liquibase-changelog-test.xml`.
  `RoomServiceImplTests` is a plain Mockito unit test and does not start Spring.
- No H2 or Testcontainers dependency; tests need the local PostgreSQL instance.
- No formatter, linter, or CI workflow; Maven test/package is the only verification.
- Reservation conflict detection counts overlapping reservations with a half-open interval:
  `existing.startDate < requested.endDate` and `existing.endDate > requested.startDate`. Adjacent
  reservations are allowed, and `canceled` reservations are not excluded.

## Auth

- JWT is HMAC-SHA256 via Spring Security's resource-server support. `POST /auth/login` with
  `{"username":"...","password":"..."}` returns `{"accessToken":"...","tokenType":"Bearer",...}`.
- Dev defaults are `admin`/`admin`; override with `APP_SECURITY_USERNAME`,
  `APP_SECURITY_PASSWORD`, `JWT_SECRET`, and `JWT_EXPIRATION`.
- Send `Authorization: Bearer <token>`. `GET /rooms`, `GET /reservations`, `/auth/login`,
  Swagger/OpenAPI, and `/actuator/health` are public; every other path is authenticated.
- Swagger/OpenAPI declares a `bearerAuth` scheme. Call `POST /auth/login`, copy `accessToken`,
  click **Authorize** and paste the token without the `Bearer ` prefix.

## Architecture

- `rest/`: controllers, request/response records, and `Converter` components from request to
  service DTO.
- `service/`: interfaces, `impl/`, DTOs, converters from DTO to entity, and domain exceptions.
- `model/`: JPA entities. `repository/`: Spring Data JPA repositories.
- Endpoints: `GET /rooms`, `GET /reservations`, `POST /rooms`, `POST /reservations`, and
  `PATCH /reservations/{id}/cancel`. The write endpoints require JWT.
- Request flow: controller -> `ConversionService` -> `Create*Dto` -> service -> converter ->
  entity -> repository. IDs are assigned with `UUID.randomUUID()` in services, not generated by JPA.
- Entities use uppercase table/column names (`ROOMS`, `RESERVATIONS`, `ROOM_ID`, etc.) and UUIDs
  stored as `VARCHAR` via `@JdbcTypeCode(SqlTypes.VARCHAR)`; Liquibase changesets must match.
